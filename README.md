# 실록 도우미

조선왕조실록(sillok.history.go.kr) 기사를 볼 때 쓰는 **크롬 확장 프로그램**이에요.
국사편찬위원회와 관계없는 **비공식** 도구예요.

- 날짜 · 제목 · 본문 · 원문 · 링크를 버튼 한 번으로 복사
- 열어 둔 엑셀에 바로 정리 (Windows)
- 키보드로 이전·다음 기사 넘기기

---

## 설치하기

### ① 확장 프로그램 설치
**[크롬 웹스토어에서 설치하기](https://chromewebstore.google.com/detail/aboehgldkknmllinigckchabkneakkpa)**

복사와 키보드 이동은 여기까지만 해도 바로 쓸 수 있어요.

### ② 엑셀 기능을 쓸 때만: 연결 프로그램 설치 (Windows)

#### ⬇ [엑셀 연결 프로그램 받기](https://github.com/segrc/sillok-tools/releases/latest/download/sillok-excel-connector.zip)

1. 위 링크를 누르면 `sillok-excel-connector.zip`이 받아져요.
2. zip을 마우스 오른쪽 버튼으로 눌러 **모두 압축 풀기** → 풀린 폴더를 **문서**처럼 지우지 않을 곳에 두세요.
3. 폴더 안의 **install.bat**을 더블클릭하세요.
   - 파란 **"Windows의 PC 보호"** 창이 뜨면 **추가 정보 → 실행**을 누르세요.
4. 실록 페이지를 새로고침하면 엑셀 버튼이 나타나요.

> 그림이 있는 자세한 안내는 확장 프로그램 아이콘 → 설정 창 → **설치 방법 보기**에서도 볼 수 있어요.

---

## 사용법

- 툴바의 **實 아이콘**을 누르면 설정 창이 열려요.
- 본문·원문에서 일부를 **드래그해 두고** 누르면 그 부분만 복사·입력돼요.
- 버튼 위 **⠿ 손잡이**를 끌면 버튼 위치를 옮길 수 있어요.
- 기본 단축키: 날짜 Alt+Q · 제목 Alt+W · 엑셀 1번 Alt+S · 엑셀 2번 Alt+A (설정 창에서 변경)

## 자주 묻는 것

- **Mac에서도 되나요?** 복사·키보드 이동은 돼요. 엑셀 기능은 Windows 전용이에요.
- **연결 프로그램 폴더를 옮겼어요.** 옮긴 폴더에서 install.bat을 다시 실행하세요.
- **지우고 싶어요.** 확장 프로그램은 크롬에서 삭제하고, 연결 프로그램은 uninstall.bat 실행 후 폴더를 지우세요.
