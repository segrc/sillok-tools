# 실록 도우미

[조선왕조실록](https://sillok.history.go.kr) 기사를 볼 때 쓰는 크롬 확장 프로그램입니다.

> 국사편찬위원회와 관계없는 **비공식** 도구입니다. 실록 본문은 이 프로그램에 들어 있지 않으며, 사용자가 열어 본 기사에서만 작동합니다.

## 할 수 있는 것

- **복사**: 날짜 · 제목 · 본문(국역) · 원문 · 링크를 버튼 한 번으로 복사
  - 날짜는 원하는 양식으로 (기본: 『세종실록』 권1, 세종 즉위년 8월 20일 정유)
  - 본문·원문은 문단 사이 빈 줄 없이 복사
- **엑셀 정리** (Windows): 열어 둔 엑셀의 맨 아래 빈 행에 날짜·제목·본문·원문·링크를 원하는 조합으로 입력
- **키보드 이동**: ←/→(또는 A/D)로 이전·다음 기사, ↑/↓(또는 W/S)로 본문 스크롤

## 설치

### 1. 확장 프로그램
크롬 웹스토어에서 **실록 도우미**를 설치하세요.
→ 웹스토어 주소: (승인 후 추가 예정)

복사와 키보드 이동은 이것만으로 바로 쓸 수 있어요.

### 2. 엑셀 연결 프로그램 (엑셀 기능을 쓸 때만, Windows 전용)
크롬 확장 프로그램은 보안상 다른 프로그램(엑셀)을 직접 다룰 수 없어서, 둘을 이어 주는 작은 프로그램을 한 번 설치해야 해요.

1. 오른쪽 **Releases**에서 `실록도우미-엑셀연결.zip`을 받아 압축을 풉니다.
2. 풀린 폴더를 지우지 않을 곳에 둡니다. (예: `내 문서`) OneDrive 동기화 폴더는 피하세요.
3. 폴더 안의 **install.bat**을 더블클릭합니다.
   - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**을 누르세요. 인터넷에서 받은 파일이라 뜨는 경고예요.
4. 실록 페이지를 새로고침하면 엑셀 버튼이 나타나요.

폴더를 옮겼다면 install.bat을 다시 실행하세요. 지우려면 **uninstall.bat**을 실행한 뒤 폴더를 지우면 돼요.

## 사용법

- 툴바의 **실록 도우미 아이콘**을 누르면 설정 창이 열려요.
  - 키보드 이동 켜기/끄기, 방향키·WASD 선택
  - 날짜 양식 고르기·추가
  - 페이지에 띄울 복사 버튼 고르기
  - 엑셀 버튼 만들기: 넣을 항목에 열 이름(A, B…)만 적으면 돼요 (최대 6개)
- 단축키: 날짜 Alt+Q, 제목 Alt+W, 엑셀 1번 Alt+S, 엑셀 2번 Alt+A
  - 설정 창 아래 **단축키 바꾸기**에서 다른 키를 지정할 수 있어요.
- 엑셀은 **입력할 시트를 앞에 띄워 둔 상태**에서 누르세요. 셀을 편집 중이면 Esc를 누른 뒤 다시 누르세요.
